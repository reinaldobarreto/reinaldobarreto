## Next.js (Static) - Python Portfolio Front (template)

Front simples para apresentar os projetos (APIs + Data Analysis) e servir como vitrine estática.

### Rodando local

```bash
npm install
npm run dev
```

### GitHub Pages

Este template está configurado para export estático via Next.js e deploy via GitHub Actions.

Pontos importantes:
- se este repositório continuar sendo `reinaldobarreto`, o `basePath` já está configurado.
- caso mude o nome do repositório, ajuste `basePath` e `assetPrefix` em `next.config.mjs`.
