## Projetos (templates)

- `django-drf-crud-api`: API REST CRUD simples (Django + Django REST Framework).
- `python-data-analysis`: análise de dados e estatística descritiva a partir de um CSV.
- `nextjs-python-portfolio`: front estático (Next.js) pronto para export e deploy no GitHub Pages.
